# GitHub LaTeX 模板对照说明

对照对象：`EthanDeng/Chinese-ERJ`，仓库说明为《经济研究》杂志 LaTeX 论文模板。该模板含 `chinese-erj.cls`、示例 `chinese-erj.tex`、参考文献 bib 文件和 PDF 示例。

## 一、来源定位

该 LaTeX 模板是第三方开源模板，不等同于《经济研究》当前官方 Word 模板。使用时应作为补充参考，不应覆盖用户提供的样张或官方投稿系统说明。

在本 skill 中，来源优先级为：

1. 用户提供的当前官方模板或投稿说明。
2. 用户提供的《经济研究》样张整理文件 `user-provided-format-spec.md`。
3. 官方网站或投稿系统可核验信息。
4. 本 LaTeX 模板等第三方模板。

## 二、一致之处

### 1. 版式与缩进

LaTeX 模板使用 `ctex`，设置中文段落首行缩进为 `2em`，与样张中的中文论文正文首行缩进习惯一致。

### 2. 中文摘要与关键词

LaTeX 模板将摘要标签定义为 `内容提要：`，并提供 `关键词：` 命令。

用户样张使用的是 `内容摘要：`。两者说明当前 skill 应允许识别 `内容摘要` 与 `内容提要`，但按用户样张进行 Word 格式化时优先使用 `内容摘要：`。

### 3. 标题层级

LaTeX 模板将一级标题格式化为中文数字加顿号，例如 `一、标题`，并居中显示。二级标题使用 `（一）` 形式并带有约 `2em` 缩进。

这与用户样张中的规则一致：

- 一级标题：`一、标题`，宋体四号，居中。
- 二级标题：`（一）标题`，前空 2 格。

### 4. 参考文献

LaTeX 模板使用 `biblatex` 和 `chinese-erj` 风格，参考文献标题为 `参考文献`，并设置较小字号。

这与用户样张中“参考文献宋体六号、不标序号、每条前空 2 格、英文和数字 Times New Roman”的方向一致，但 LaTeX 模板未直接对应 Word 中“每条前空 2 格”的实现细节。

### 5. 图表标题

LaTeX 模板通过 `caption` 设置图表标题小号字体、标签加粗，并设置图表标题与图表间距。

这与用户样张中“表格标题清晰居中、图题黑体小五居中”的方向一致，但 Word 样张对字体要求更具体。

### 6. 英文信息

LaTeX 模板包含英文标题、英文作者、英文机构、Summary、Keywords、JEL Classification 的结构。

这支持 skill 审查器继续检查 Summary、Key Words / Keywords、JEL Classification 等英文前后置信息。

## 三、差异与处理原则

### 1. `内容摘要` 与 `内容提要`

- 用户样张：`内容摘要：`
- LaTeX 模板：`内容提要：`

处理原则：格式化 Word 稿件时优先样张 `内容摘要：`；审查时同时接受 `内容摘要`、`内容提要` 和 `摘要：`。

### 2. 字号体系

LaTeX 使用 `\huge`、`\Large`、`\large`、`\small`、`\scriptsize` 等相对字号；用户样张给出 Word 字号，如宋体三号/小三、小四、五号、四号、小五、六号。

处理原则：Word skill 以用户样张的 Word 字号为准，LaTeX 的相对字号只用于判断层级大小关系。

### 3. 参考文献实现方式

LaTeX 模板依赖 `biblatex` 和 `chinese-erj` 样式；Word 稿件无法自动复现完整 BibLaTeX 排序、作者缩写和期刊斜体逻辑。

处理原则：Word skill 只做保守规范化和审查提醒；若需要逐条参考文献精修，应另行进行文献核对。

### 4. 页眉页脚

LaTeX 模板带有工作论文页眉和 logo 设置；用户样张没有要求投稿 Word 稿件保留该页眉。

处理原则：Word skill 不添加 LaTeX 模板页眉、logo 或工作论文标识。

### 5. 页边距

LaTeX 模板设置约左/右 27.6mm、上 32.7mm、下 28mm。用户样张图片未明确页边距。

处理原则：Word skill 继续采用保守页边距，不把 LaTeX 页边距作为硬性要求，除非用户提供官方 Word 模板。

## 四、对 Skill 的影响

当前 skill 的实现与 LaTeX 模板对照后保留以下策略：

- 继续将用户样张作为 Word 格式化的主要依据。
- 审查器同时接受 `内容摘要：` 与 `内容提要：`。
- 保留 Summary、Key Words / Keywords、JEL Classification 检查。
- 保留 `一、`、`（一）`、`1.`、`（1）` 的标题层级判断。
- 保留参考文献小字号、无序号、每条前空 2 格、英文数字 Times New Roman 的 Word 样张规则。
- 不引入 LaTeX 模板中的页眉、logo、工作论文标识。
