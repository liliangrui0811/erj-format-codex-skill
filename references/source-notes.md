## Not Reliably Found

No clearly current, directly downloadable official Word template or latest author-format PDF was reliably found through public search at creation time.

## Practical Policy

When formatting a real manuscript:

- If the user provides a current guide/template, use it as controlling authority.
- If the user does not provide one, apply the conservative rules in `erj-format-rules.md`.
- In the format report, separate "applied" items from "needs final official confirmation" items.
- Do not invent exact requirements for margins, line counts, font sizes, Summary length, or anonymous-review placement when the evidence is not current.
